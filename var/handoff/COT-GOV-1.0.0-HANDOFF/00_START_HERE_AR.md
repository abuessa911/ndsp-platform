# نقطة البداية — مشروع COT-GOV-1.0.0

## الغرض من هذه الحزمة

هذه حزمة تسليم ومواصفات مرجعية لتحديث طبقة اتجاه COT وطبقة التوقيت داخل مشروع:

`/home/nawaf511/empire-core-new`

الحزمة لا تستبدل ملفات الإنتاج تلقائياً، ولا تعدّل Nginx أو systemd، ولا تحذف أي مسار قديم. يجب أولاً مراجعة الكود الحالي، وإعداد خريطة أثر، وتشغيل الاختبارات ووضع الظل.

## القرارات المعتمدة

1. دلتا الغلبة هي الفارق العددي بين Long وShort داخل مجموعة البيانات نفسها، وليست فارقاً زمنياً.
2. Long أكبر من Short يعني صاعد، ولو بعقد واحد.
3. Short أكبر من Long يعني هابط، ولو بعقد واحد.
4. المحايد لا يظهر إلا عند التساوي التام.
5. كل نتيجة تعرض بالاتجاه والصراحة والأفق.
6. النمط الاستثماري:
   - الاتجاه الكلي الرسمي من Positions لمدراء الأصول فقط.
   - Changes لمدراء الأصول تستخدم للدعم الأسبوعي فقط.
   - منطق أيام السيطرة وTDL-M&L وTDL-S والتوقيت معطلة.
   - عند مخالفة الدعم الأسبوعي للاتجاه الكلي، يستمر عرض الاتجاه الكلي مع:
     «الدعم الأسبوعي غير متحقق».
7. النمط المضاربي:
   - يستخدم Changes فقط.
   - يستخدم منطق أيام السيطرة.
   - منطق TDL-M&L وTDL-S مسموح فقط داخل المضاربة.
8. UTC هو المرجع الزمني الوحيد.
9. تقرير الثلاثاء يبدأ تطبيقه من الاثنين التالي 00:00 UTC حتى الاثنين الذي يليه، بنطاق نصف مفتوح.
10. CORE هو المخرج الرسمي ويستخدم فئة واحدة.
11. EXPANDED يعمل في Shadow Mode ويستخدم الفئات المجمعة ولا يظهر للمستخدم.
12. جذر المشروع الرسمي:
    `/home/nawaf511/empire-core-new`
13. المطلوب إنهاء الاعتماد تدريجياً على:
    `/opt/empire-core`
    `/root/empire-core`
    `/var/www`
14. لا يتم حذف المسارات القديمة قبل Dry Run ونسخة احتياطية واختبارات قبول وخطة رجوع.

## ما لم يُحسم بعد

- تفاصيل قواعد TDL-M&L الحالية.
- تفاصيل قواعد TDL-S الحالية.
- الملفات الفعلية التي تطبق الاتجاه والتوقيت في الكود القديم.
- نموذج التخزين وقاعدة البيانات المستخدمة للنتائج الرسمية والتجريبية.
- نقاط التكامل الدقيقة داخل main.cjs قبل مراجعته.

لهذا السبب تتضمن الحزمة واجهات قابلة للحقن وإعدادات وعقوداً، ولا تخترع منطق TDL غير موثق.
