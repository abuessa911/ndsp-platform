لدي مشروع واجهات لمنصة **NDSP — منصة دعم القرار** مبني بـReact + Vite + TypeScript. افتح الحزمة المرفقة واقرأ `README.md` و`AGENTS.md` أولًا، ثم طوّر المشروع من داخل بنيته الحالية دون إعادة إنشاء التصميم من الصفر.

التزم بهوية **Sovereign Meridian**: خلفية Carbon Black، ذهب Meridian، أزرق Intelligence Blue، خط IBM Plex Sans Arabic للعربية وInter للإنجليزية، واتجاه RTL للواجهات العربية مع بقاء JSON والأكواد والتواريخ LTR.

حافظ على هذه الحدود الهندسية:

- الصفحات العامة تعرض نتيجة CORE الرسمية فقط.
- EXPANDED يعمل في SHADOW MODE داخل `/admin/cot` فقط.
- لا يوجد مسار مباشر من EXPANDED إلى Public API.
- أي ترقية تمر عبر Governance Promotion Request واختبارات واعتماد.
- لا تغيّر الأصول الأصلية في `public/assets/` ولا تعِد رسم الشعار أو مسار القرار باستخدام CSS أو SVG يدوي.

المصادقة مربوطة حاليًا بعقود `/api/auth/*` ذات المصدر نفسه، ولوحة الإدارة خلف `RequireAdmin` مغلق افتراضيًا. لا تستبدل ذلك بمصادقة وهمية، ولا تضع أسرارًا في الواجهة.

بيانات `src/data.ts` ما زالت بيانات عرض، وصفحات بوابة المستخدم الفعلية غير موجودة في هذه الحزمة. لا تدّعِ جاهزية الإنتاج، ولا تحذف البوابة الحالية، قبل نقل صفحات المستخدم وربط بيانات الصفحات واختبار Docker edge routing.
