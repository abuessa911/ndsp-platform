# الغرض:
# إصلاح التعريب وزر اللغة وقائمة الجوال من المصدر أو من runtime واحد فقط، بدون تغيير التصميم الحالي أو حذف محتوياته.

أنت تعمل على:

## 0) القواعد غير القابلة للتفاوض

ممنوع:
- لا تغيّر التصميم البصري العام.
- لا تغيّر الألوان أو الثيم أو الهوية.
- لا تحذف أي صفحة.
- لا تغيّر أسماء الصفحات الرسمية.
- لا تلمس API أو backend أو database أو Nginx أو PM2 أو systemd.
- لا تضف Buy/Sell أو أي لغة تنفيذ.
- لا تكشف أسماء محركات داخلية أو مزودين داخليين.
- لا تخترع NMP.
- لا تعرض بيانات وهمية كأنها live.
- لا تكدس سكربتات جديدة فوق D11.
- لا تنشئ runtime JS جديد إذا كان بالإمكان تعديل runtime D11 الحالي.
- لا تعدل protected assets:
  /var/www/ndsp-my/assets/ndsp-radar-safe-clean.js
  /var/www/ndsp-my/assets/ndsp-global-menu.js
  /var/www/ndsp-my/assets/ndsp-disclaimer-gate.js

مسموح:
- إصلاح ملف التعريب الحالي إن كان موجودًا:
  /var/www/ndsp-my/approved-design/ndsp-full-ar-i18n-v18-d11.js
- أو نقل التعريب إلى المصدر إن كان source المعتمد موجودًا، بشرط عدم تغيير التصميم.
- إضافة زر لغة يعمل دائمًا.
- إضافة زر قائمة للجوال فقط إذا كانت نسخة الجوال بلا قائمة.
- إضافة طبقة تحقق/تقرير read-only لقياس العناصر المطلوبة.
- إضافة backup + report + post-patch test.

## 1) سبب المهمة

المشكلة الحالية:
1. زر تغيير اللغة يعمل مرة واحدة فقط، وبعدها لا يستجيب إلا بعد refresh.
2. التعريب غير كامل لكل الصفحة.
3. نسخة الجوال لا يظهر فيها زر واضح للقوائم.
4. مطلوب التأكد من وجود عناصر غرفة القرار بدون حذف أو تغيير محتوى التصميم الحالي.
