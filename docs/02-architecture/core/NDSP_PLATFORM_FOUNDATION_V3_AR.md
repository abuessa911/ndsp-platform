# NDSP Platform Foundation V3

تجمع هذه الحزمة بين:

1. السجل القانوني للطبقات الست عشرة.
2. سجل قدرات المنصة المستقل.
3. سجل الأصول والرموز الموحد.
4. سجل المصادر.
5. سجل العقود والمخططات.
6. بوابات الجودة والمصالحة والحداثة.
7. التخزين الخام والنسخة القانونية المقبولة.
8. نسب البيانات والتتبع والسجل الدليلي.
9. حوكمة المحركات والنماذج والسياسات.
10. المختبرات والمحاكاة.
11. المراقبة عبر OpenTelemetry.
12. الأخبار والأحداث والسياق العابر للأصول.
13. محرك التعارض والتأكيد.
14. التفسير والتقييم.
15. التخصيص والصلاحيات والتكاملات والفوترة.
16. الأمن والنسخ الاحتياطي وجدولة سير العمل.
