# NDSP Platform Foundation V3

This package combines the canonical 16-layer core with an independent platform
capability registry, asset and source identity, contracts, quality and
reconciliation, snapshots and lineage, evidence, governance, replay,
observability, context intelligence, conflict analysis, explainability,
evaluation, personalization, access, integrations, billing, security,
recovery and workflow orchestration.

Activation state:
`INSTALLED_AND_TESTED_NOT_LIVE`

The live orchestrator, wrappers, API gateway, services and databases are not
modified by this package.
