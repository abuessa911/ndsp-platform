# ملاحظة جاهزية دليل المستخدم

## النتيجة

تم إنشاء دليل مستخدم عربي مستقل يشرح طريقة قراءة المنظومة للمستخدم العادي والمحترف.

## ما الذي يعالجه الدليل؟

- تعريف NDSP كغرفة دعم قرار.
- شرح قوة القراءة مقابل جاهزية القرار.
- شرح حالات القراءة.
- شرح مستويات السيناريو.
- شرح TDL و NMP وإشارة نواف الذهبية ومحامي الشيطان.
- توضيح الفرق بين عرض المبتدئ والمحترف.
- تثبيت التحذير القانوني بأن المخرجات ليست أوامر تداول.

## ما الذي لا يفعله هذا التحديث؟

- لا يعدل الباندل.
- لا يغير React.
- لا يحذف صفحات.
- لا يعيد تشغيل الخدمات.
- لا يغير API.
- لا يغير التصميم الحالي.
