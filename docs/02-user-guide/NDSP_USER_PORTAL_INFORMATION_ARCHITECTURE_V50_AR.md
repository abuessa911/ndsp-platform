# هندسة بوابة المستخدم — NDSP v50

## التسلسل الحاكم

1. اختيار السوق.
2. اختيار الأصل.
3. اختيار الفريم.
4. اختيار نوع القراءة: استثمارية أو مضاربية.
5. اختيار مستوى العرض: بسيط أو محترف.
6. إنشاء جلسة قرار مقفلة بالسياق.
7. عرض ملخص القرار والحالة الحاكمة.
8. عرض قوة القراءة مقابل جاهزية القرار.
9. شرح سبب عدم الاكتمال.
10. مستويات السيناريو وNMP.
11. الشرح البسيط ثم المحترف.
12. السيناريو الحاكم والسيناريوهات البديلة.
13. المخاطر والسياق الكلي ومحامي الشيطان.
14. الأدلة التحليلية والطبقات الست عشرة.
15. قدرات المنصة الثماني والعشرون بصورة منفصلة عن سلطة القرار.
16. القرارات المكتملة والسجل وصحة البيانات.

## قاعدة منع اختلاط الأصول

لا يبدأ استدعاء محركات القرار قبل اكتمال: السوق + الأصل + الفريم + نوع القراءة. كل استجابة تحمل سياقًا متوقعًا، وأي اختلاف في الرمز أو الفريم يمنع عرض النتيجة ويظهر تنبيه حوكمة.
