# قفل اكتمال وترقيم طبقات NDSP — V1

## القانون

لا يجوز تثبيت أو تشغيل أو دمج أي حزمة طبقات إذا لم تحقق جميع الشروط:

1. وجود 16 طبقة بالضبط.
2. تسلسل المعرفات من NDSP-CORE-L01 إلى NDSP-CORE-L16 دون فجوات.
3. اسم قانوني واحد لكل رقم مطابق للسجل الرسمي.
4. ملف قانوني واحد لكل طبقة داخل المصدر المعتمد.
5. عدم استبدال رقم بطبقة أخرى أو إخفاء طبقة داخل ملف عام.
6. فشل الاختبار فور غياب L07 أو L09 أو أي طبقة أخرى.
7. السجل الرسمي هو المرجع، وليس الذاكرة أو أسماء الملفات القديمة.

## الترتيب الرسمي

L01 TDL المتوسط والطويل  
L02 TDL القصير والمضاربي  
L03 اتجاه السوق الحاكم  
L04 بوابة التصحيح  
L05 محرك الانحراف  
L06 منطق الزمن والأيام  
L07 مستويات السيناريو  
L08 نقطة الالتقاء NMP  
L09 محرك الزخم  
L10 تأكيد البنية والسيولة  
L11 فلتر الدولار والسياق الكلي  
L12 محرك المخاطر  
L13 إشارة نواف الذهبية  
L14 إشارة نواف الذهبية المعززة  
L15 محامي الشيطان  
L16 الجاهزية وآلة حالات القرار
