# NDSP V1 Freeze

This is V1. Anything outside scope is deferred until V1 is complete and acceptance tests pass.

## Inside V1
Landing, registration, login, 16-day trial, disclaimer, user portal, decision support, asset view, command center, daily brief, settings and alerts, live decision API, live price, radar, sidebar, hidden secret engines.

## Outside V1
Trading bot, broker execution, native mobile app, full engine disclosure, complex enterprise expansion.

## Rule
No scope expansion without a new patch plan or release plan.
