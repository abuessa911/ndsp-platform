# NDSP V1 Freeze — تجميد نطاق النسخة الأولى

## القاعدة

هذه نسخة V1.
أي شيء خارج النطاق يؤجل حتى تكتمل V1 وتنجح اختبارات القبول.

## داخل V1

- صفحة الهبوط
- التسجيل
- تسجيل الدخول
- تجربة 16 يوم
- إخلاء المسؤولية
- بوابة المستخدم
- صفحة دعم القرار
- صفحة عرض الأصل
- مركز القرار
- يوميات القرار
- الإعدادات والتنبيهات
- API القرار الحي
- السعر الحي
- الرادار
- القائمة الجانبية
- منع Buy/Sell
- إخفاء المحركات السرية
- تثبيت عقود غرفة القرار
- تثبيت مختبرات الإدارة كحكم داخلي

## خارج V1

- بوت تداول
- تنفيذ صفقات
- ربط وسيط تداول
- تطبيق جوال مستقل
- كشف كامل للمحركات
- توصيات مالية مباشرة
- إعادة بناء شاملة للواجهة
- تغيير تصميم عام بدون سبب
- تكديس سكربتات جديدة بلا عقد

## ممنوع أثناء V1

- لا تغيير أسماء الصفحات الرسمية.
- لا حذف الرادار.
- لا حذف القائمة الجانبية.
- لا حذف إخلاء المسؤولية.
- لا كشف الطبقات السرية.
- لا إضافة أوامر شراء أو بيع.
- لا تعديل الباك إند لإصلاح مشكلة واجهة إلا بعد إثبات السبب.
- لا إعادة بناء شاملة قبل تثبيت الوضع الحالي.
- لا إنشاء route أو page مكرر باسم قريب من صفحة رسمية.
- لا عرض بيانات static كأنها live.
- لا اختراع NMP من الواجهة.

## أولويات V1 بعد الفحص

1. تثبيت حقيقة التشغيل: PM2 أم systemd.
2. تثبيت مصدر الصفحات: static أم SPA fallback.
3. تثبيت إخلاء المسؤولية قبل البوابة.
4. تثبيت الرادار والقائمة ضد الاختفاء.
5. تثبيت عقد API بين الواجهة والباك إند.
6. تشغيل post-patch test بعد كل تعديل.
